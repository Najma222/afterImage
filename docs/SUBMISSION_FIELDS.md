# Submission fields to collect before publishing

Fill these in with real values. Do not invent any of them.

## DEV post
- [ ] DEV username/profile URL
- [ ] Exact challenge tag from the official Week 4 page
- [ ] Official submission template copied from the challenge page
- [ ] Final post title
- [ ] Public GitHub repository URL
- [ ] Live demo URL, or public video walkthrough URL
- [ ] Screenshot/GIF URLs or uploaded images
- [ ] Exact model name and tag used in the final build
- [ ] Model license/terms source
- [ ] Actual inference route (local Ollama / hosted inference / other)
- [ ] Actual partner category/categories entered, if any
- [ ] What you personally built and learned
- [ ] Known limitations and future work
- [ ] Confirmation of eligibility and official rules
- [ ] Published post URL and proof it is public

## GitHub repository
- [ ] Repository name: `byte-buddy`
- [ ] Public visibility
- [ ] Description: “A cozy memory adventure powered by open-weight AI.”
- [ ] README with setup and demo
- [ ] Screenshots
- [ ] Appropriate code license chosen by the project owner
- [ ] Model and third-party asset attribution
- [ ] No API keys, passwords, or local machine paths
- [ ] No generated files or virtual environment committed

## Demo recording (60–90 seconds)
- [ ] Landing screen and premise
- [ ] Start game
- [ ] Click an object and show puzzle
- [ ] Show a real AI response, if model integration is claimed
- [ ] Solve a puzzle and show progress update
- [ ] Complete all three memories and show ending
- [ ] Show the AI explanation/fallback behavior
- [ ] Narrate what open-weight AI contributes

## Partner category evidence (optional)
For each category, write down:
- Category name exactly as listed on the official Week 4 page
- Partner technology/product used
- File path or feature where it is integrated
- What user-visible capability it enables
- Screenshot/log/video proving it works
- Any category-specific requirement and how the project satisfies it

Only select a category if you can point to meaningful, working integration evidence.
